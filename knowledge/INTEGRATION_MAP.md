## 🔄 ДЕТАЛЬНАЯ МАТРИЦА ИНТЕГРАЦИИ

### Входящие данные для каждого агента

#### 🎯 МЕНЕДЖЕР
```
ВХОДИТ ОТ:
  - Пользователь (задача)

ВХОДЯЩИЕ ДАННЫЕ:
  - Текстовое описание задачи
  - Дедлайны
  - Бюджет
  - Целевая аудитория
  - Тема контента

ВЫХОДИТ К:
  - Scout, Strategist, Copywriter, Video Editor, etc.
```

#### 🕵️ СКАУТ
```
ВХОДИТ ОТ:
  - Менеджер (приказ)

ВХОДЯЩИЕ ДАННЫЕ:
  - Тема (например: "Славяно-Арийская культура")
  - Сроки (3 дня)
  - API ключи (YouTube, VK, Instagram, Trendsee, LiveDune)

ВЫХОДИТ К:
  - Strategist (анализ)
  - Trend Analyst (для анализа)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - ТОП-5 видео с метриками
  - Ссылки на видео
  - Views, likes, comments, shares
  - Ratio виральности
```

#### 📊 СТРАТЕГ
```
ВХОДИТ ОТ:
  - Менеджер (приказ)
  - Scout (ТОП-5 видео)

ВЫХОДИТ К:
  - Trend Analyst (рекомендации)
  - Copywriter (стратегия контента)
  - Promotion Manager (план публикации)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Стратегический план
  - Целевая аудитория (описание)
  - Факторы виральности
  - Рекомендуемые даты публикации
  - Ожидаемые метрики
```

#### 🔥 ТРЕНДОЛОГ
```
ВХОДИТ ОТ:
  - Strategist (рекомендации)
  - Scout (5 видео)

ВЫХОДИТ К:
  - Copywriter (анализ для промптов)
  - Audience Researcher (для persona development)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Транскрибация (текст видео)
  - Структура (хук, тема, призыв)
  - Ключевые фразы
  - Психологические триггеры
  - Рекомендации для переписывания
```

#### ✍️ КОПИРАЙТЕР
```
ВХОДИТ ОТ:
  - Trend Analyst (анализ видео)
  - Audience Researcher (информация об аудитории)

ВЫХОДИТ К:
  - Promotion Manager (15 промптов для публикации)
  - Email Specialist (основа для email текстов)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - 15 промптов (3 на видео)
  - Вариант A (эмоциональный)
  - Вариант B (логический)
  - Вариант C (urgency)
```

#### 👥 AUDIENCE RESEARCHER
```
ВХОДИТ ОТ:
  - Trend Analyst (анализ из видео)
  - Strategist (целевой рынок)

ВЫХОДИТ К:
  - Copywriter (для адаптации текстов)
  - Email Specialist (для сегментации)
  - Sales Agent (для sales скриптов)
  - Community Manager (для общения с аудиторией)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Buyer Personas (3-5)
  - Болевые точки (pain points)
  - Психологические триггеры
  - Рекомендации по контенту
```

#### 🎬 ВИДЕО-РЕДАКТОР
```
ВХОДИТ ОТ:
  - Scout (5 исходных видео)
  - Trend Analyst (рекомендации)
  - Copywriter (промпты)

ВЫХОДИТ К:
  - Format Creator (для адаптации под платформы)
  - Promotion Manager (15 готовых видео)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - 15 видеороликов (5 видео × 3 платформы)
  - 3 версии для TikTok, Instagram, YouTube
  - Сжатые файлы готовые к публикации
```

#### 🎨 МУЛЬТИФОРМАТНИК
```
ВХОДИТ ОТ:
  - Video Editor (15 видео)

ВЫХОДИТ К:
  - Promotion Manager (готовый к публикации контент)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Оптимизированные видео для каждой платформы
  - Графика и визуальный контент
  - Хэштеги и описания
```

#### ⚙️ AUTOMATION SPECIALIST
```
ВХОДИТ ОТ:
  - Format Creator (готовый контент)
  - Promotion Manager (требования к публикации)

ВЫХОДИТ К:
  - Promotion Manager (workflow'ы для публикации)
  - Email Specialist (интеграция CRM)
  - Community Manager (интеграция комментариев)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Zapier/Make workflows
  - Telegram Bot API
  - Webhook'и для интеграции
  - Расписание публикаций
```

#### 📢 PROMOTION MANAGER
```
ВХОДИТ ОТ:
  - Automation Specialist (workflows)
  - Format Creator (контент)
  - Copywriter (промпты)

ВЫХОДИТ К:
  - Community Manager (комментарии)
  - Analytics Specialist (метрики)
  - Email Specialist (контакты для email)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Опубликованные видео в 4 сетях
  - Трафик (views, likes, comments)
  - Список теплых leads из Telegram
  - Метрики по платформам
```

#### 💬 COMMUNITY MANAGER
```
ВХОДИТ ОТ:
  - Promotion Manager (комментарии из соц. сетей)

ВЫХОДИТ К:
  - Sales Agent (горячие leads)
  - Analytics Specialist (инсайты)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Ответы на комментарии
  - Модерация
  - Список горячих leads (заинтересованные)
  - Инсайты о потребностях аудитории
  - Идеи для новых видео
```

#### 📧 EMAIL SPECIALIST
```
ВХОДИТ ОТ:
  - Promotion Manager (список Telegram подписчиков)
  - Copywriter (основа для email текстов)

ВЫХОДИТ К:
  - Sales Agent (теплые leads, ready to buy)
  - Analytics Specialist (метрики открытий)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Email-последовательность (5-7 писем)
  - Сегментированные списки
  - Метрики открытий и кликов
  - Список горячих leads
```

#### 💰 SALES AGENT
```
ВХОДИТ ОТ:
  - Email Specialist (горячие leads)
  - Community Manager (очень заинтересованные)
  - Audience Researcher (информация об аудитории)

ВЫХОДИТ К:
  - Analytics Specialist (факт продажи + размер)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Лендинг страницы
  - Sales скрипты
  - Закрытые продажи
  - Доход
  - Отзывы клиентов
```

#### 🧪 A/B TESTING SPECIALIST
```
ВХОДИТ ОТ:
  - Analytics Specialist (метрики)
  - Promotion Manager (контент)
  - Email Specialist (результаты email)

ВЫХОДИТ К:
  - Copywriter (рекомендации по улучшению)
  - Video Editor (рекомендации по видео)
  - Strategist (рекомендации по стратегии)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Результаты A/B тестов
  - Статистический анализ
  - Рекомендации по оптимизации
  - Гипотезы для следующего цикла
```

#### 📊 ANALYTICS SPECIALIST
```
ВХОДИТ ОТ:
  - Promotion Manager (метрики из соц. сетей)
  - Email Specialist (метрики email)
  - Sales Agent (факты продаж)
  - A/B Testing (результаты тестов)

ВЫХОДИТ К:
  - Menager (полный отчет)
  - Strategist (рекомендации)
  
ВЫХОДЯЩИЕ ДАННЫЕ:
  - Еженедельный отчет
  - ROI расчеты
  - Метрики по платформам
  - Прогнозы на следующий месяц
```

## 🔀 ПАРАЛЛЕЛЬНЫЕ ПРОЦЕССЫ

### Какие агенты могут работать одновременно?

```
ДНЬ 1-3: ПАРАЛЛЕЛЬНО
  🕵️ Scout ≈ 📊 Strategist (оба начинают в одно время)

ДНЬ 3-4: ПАРАЛЛЕЛЬНО
  🔥 Trend Analyst ≈ [ничего не мешает]

ДНЬ 4: ПАРАЛЛЕЛЬНО
  ✍️ Copywriter ≈ 👥 Audience Researcher (независимо друг от друга)

ДНЬ 4-5: ПАРАЛЛЕЛЬНО
  🎬 Video Editor ≈ ⚙️ Automation Specialist (готовят базу)

ДНЬ 5-6: ПАРАЛЛЕЛЬНО
  🎨 Format Creator ≈ [ничего не мешает]

ДНЬ 6+: ПАРАЛЛЕЛЬНО (24/7)
  📢 Promotion Manager ≈ 💬 Community Manager ≈ 📧 Email Specialist
  (все работают одновременно, каждый на своём)

ДНЬ 6-14: ПАРАЛЛЕЛЬНО
  💰 Sales Agent ≈ 🧪 A/B Testing ≈ 📊 Analytics (ongoing)
```

## 📬 ПОТОК ДАННЫХ ПО ДНЯМ

### ДЕНЬ 1-3

```
🎯 Менеджер: "Scout, найди ТОП-5!"
  ↓ (параллельно)
🕵️ Scout работает (24 часов поиска) ≈ 📊 Strategist готовится
  ↓
🎯 Менеджер получает ТОП-5
```

### ДЕНЬ 3

```
🕵️ Scout → 🔥 Trend Analyst: "Вот 5 видео, проанализируй"
           → 📊 Strategist: "Вот 5 видео, дай стратегию"
  ↓ (параллельно)
🔥 Trend Analyst анализирует ≈ 📊 Strategist анализирует
  ↓
(результаты готовы к концу дня)
```

### ДЕНЬ 4

```
🔥 Trend Analyst → ✍️ Copywriter: "Вот анализ, создай промпты"
                 → 👥 Audience Researcher: "Информация для персон"
  ↓ (параллельно)
✍️ Copywriter создает 15 промптов ≈ 👥 Audience Researcher создает персоны
  ↓
(результаты готовы к концу дня)
```

### ДЕНЬ 4-5

```
🔥 Trend Analyst → 🎬 Video Editor: "Вот анализ и видео, монтируй"
                 → ⚙️ Automation Specialist: "Подготовь workflows"
  ↓ (параллельно)
🎬 Video Editor монтирует (29 часов) ≈ ⚙️ Automation Specialist готовит интеграции
  ↓
(видео готовы к концу дня 5)
```

### ДЕНЬ 5-6

```
🎬 Video Editor → 🎨 Format Creator: "Вот 15 видео, адаптируй"
  ↓
🎨 Format Creator адаптирует (6 часов)
  ↓
(контент готов)
```

### ДЕНЬ 6+

```
(все готово)
  ↓
⚙️ Automation Specialist → 📢 Promotion Manager: "Workflows готовы, публикуй"
  ↓ (параллельно, 24/7)
📢 Promotion Manager публикует
  ≈ 💬 Community Manager отвечает на комментарии
  ≈ 📧 Email Specialist отправляет письма
  ≈ 💰 Sales Agent закрывает продажи
  ≈ 🧪 A/B Testing тестирует
  ≈ 📊 Analytics собирает метрики
```

## 🔄 ОБРАТНАЯ СВЯЗЬ МЕЖДУ АГЕНТАМИ

### Feedback Loop (Обучение и Оптимизация)

```
📊 Analytics → 🧪 A/B Testing: "Вот метрики, что тестировать?"
  ↓
🧪 A/B Testing → ✍️ Copywriter: "Промпты A лучше чем B, измени текст"
                → 🎬 Video Editor: "Видео с эффектом X работает лучше"
                → 📊 Strategist: "Длинные видео работают лучше коротких"
  ↓
✍️ Copywriter, 🎬 Video Editor, 📊 Strategist: "Применяем рекомендации"
  ↓
Следующий цикл: результаты ЛУЧШЕ
  ↓
(система постоянно улучшается)
```

## 📊 ВРЕМЯ ПРОХОЖДЕНИЯ ПО ЭТАПАМ

```
ВХОДЯЩИЕ ДАННЫЕ (от Менеджера) → 3 дня → ПОИСК
                                    1 день → АНАЛИЗ
                                    1 день → ТЕКСТ + АУДИТОРИЯ
                                   2 дня → ВИДЕО + ИНТЕГРАЦИЯ
                                    1 день → ФИНАЛИЗАЦИЯ
                                  ─────────────────────────
                                   ≈ 8-9 дней → ПУБЛИКАЦИЯ
                                   
ПУБЛИКАЦИЯ → 7 дней → EMAIL + SALES (горячие leads)
                   → 14+ дней → ПОЛНАЯ КОНВЕРСИЯ
                   → ongoing → ОПТИМИЗАЦИЯ
```

## 🚀 КАК МАСШТАБИРОВАТЬ?

### Если запустить 2 цикла одновременно:

```
ЦИКЛ #1 (дни 1-14):
  День 1-3: Scout поиск
  День 3-9: Анализ + Монтаж
  День 6+: Публикация

ОДНОВРЕМЕННО с ЦИКЛОМ #1:

ЦИКЛ #2 (дни 8-21):
  День 8-10: Scout поиск (новое видео)
  День 10-16: Анализ + Монтаж
  День 13+: Публикация

РЕЗУЛЬТАТ:
  2x видео в месяц → 2x трафик → 2x доход → 2x объемы
```

### Если запустить 4 цикла (максимум):

```
ЦИКЛ #1: дни 1-14
ЦИКЛ #2: дни 8-21 (сдвиг на 7 дней)
ЦИКЛ #3: дни 15-28 (сдвиг на 14 дней)
ЦИКЛ #4: дни 22-35 (сдвиг на 21 день)

РЕЗУЛЬТАТ:
  Каждый день выходит новое видео!
  4x трафик → 4x доход → профит 💰
```
