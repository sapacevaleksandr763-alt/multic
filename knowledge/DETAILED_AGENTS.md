## 🎯 АГЕНТ #1: МЕНЕДЖЕР (Manager Agent)

### Основная информация
```
Статус:     ✅ Существует
Приоритет:  ⭐⭐⭐ КРИТИЧНЫЙ
Роль:       Координация всех агентов
Версия:     v3.0
```

### Основные функции
```
1. Получить задачу от пользователя
   Входит: Текстовое описание задачи
   Выходит: Разбор на подзадачи

2. Выдать приказы другим агентам
   Входит: План выполнения
   Выходит: Команды для Scout, Strategist, etc.

3. Мониторить прогресс
   Входит: Отчеты от других агентов
   Выходит: Статус, предупреждения, коррекции

4. Контролировать качество
   Входит: Готовый контент от всех агентов
   Выходит: Утверждение или требование доработки

5. Управлять сроками
   Входит: План с дедлайнами
   Выходит: Ежедневные чек-пойнты, сигналы о задержках
```

### Входящие данные
```
- Задача от пользователя (текст)
- Дедлайны
- Бюджет
- Целевая аудитория
- Тема контента
```

### Выходящие данные
```
- Приказ Scout Agent: "Найди ТОП-5 видео по теме..."
- Приказ Strategist: "Проанализируй факторы виральности..."
- Приказ Copywriter: "Создай 15 промптов..."
- И т.д. для каждого агента
```

### Процесс работы
```
Шаг 1: Получить задачу
Шаг 2: Разложить на подзадачи
Шаг 3: Определить последовательность (какие параллельно, какие на что ждут)
Шаг 4: Выдать приказы
Шаг 5: Мониторить выполнение (каждый день)
Шаг 6: Корректировать при необходимости
Шаг 7: Получить итоговый результат от Promotion Manager
Шаг 8: Доложить пользователю
```

### Примеры команд
```
Manager → Scout: "Scout, найди ТОП-5 видео по теме 'Славяно-Арийская история' за 3 дня"
Manager → Strategist: "Strategist, проанализируй эти 5 видео и выдай стратегию"
Manager → Copywriter: "Copywriter, на основе анализа создай 15 промптов"
Manager → Video Editor: "Video Editor, смонтируй 15 видео из 5 исходных"
Manager → Promotion Manager: "Promotion Manager, опубликуй 15 видео в 4 сетях и начни мониторинг"
```

### Скиллы которые нужны
```
- Проектный менеджмент
- Организация работы
- Контроль качества
- Управление временем
- Коммуникация
```

## 🕵️ АГЕНТ #2: СКАУТ (Scout Agent)

### Основная информация
```
Статус:     ✅ Спроектирован (SCOUT_AGENT_*.md)
Приоритет:  ⭐⭐⭐ КРИТИЧНЫЙ
Роль:       Поиск ТОП-5 вирусных видео
Версия:     v4.0
Время:      3 дня
```

### Основные функции
```
1. Поиск на YouTube по ключевым словам
2. Анализ метрик (views, likes, comments, shares)
3. Фильтрация по вирусности (2-3x ratio views/subs)
4. Сравнение с конкурентами
5. Выявление трендов
6. Ранжирование по потенциалу
7. Выдача ТОП-5 с данными
```

### Входящие данные
```
- Тема (например: "Славяно-Арийская культура")
- Сроки (3 дня)
- API ключи (YouTube, VK, Instagram, Trendsee, LiveDune)
```

### Выходящие данные
```
ТОП-5 видео с:
  - Ссылка на видео
  - Количество просмотров
  - Количество лайков
  - Количество комментариев
  - Количество шер
  - Ratio виральности (views/subs)
  - Почему это видео "залетело"
  - Целевая аудитория (предположение)
  - Рекомендация по адаптации
```

### Источники данных
```
Бесплатные API:
  - YouTube Data API v3
  - VK API (VKontakte)
  - Instagram Basic Display API
  
Платные API:
  - Trendsee API (получение трендов)
  - LiveDune API (аналитика видео)
  - SocialBlade (метрики YouTube)

Ручной поиск:
  - YouTube Trending
  - VK Trending
  - Instagram Explore
  - TikTok For You Page
```

### Процесс работы (3 дня)
```
ДЕНЬ 1 (8 часов):
  Шаг 1: Собрать ключевые слова (варианты)
  Шаг 2: Поиск на YouTube (первые 500 результатов)
  Шаг 3: Поиск в VK (первые 300 видео)
  Шаг 4: Первичная фильтрация по просмотрам

ДЕНЬ 2 (8 часов):
  Шаг 5: Глубокий анализ топ-100 видео
  Шаг 6: Расчет ratio виральности для каждого
  Шаг 7: Выявление трендов
  Шаг 8: Второй раунд поиска по выявленным трендам

ДЕНЬ 3 (8 часов):
  Шаг 9: Финальный анализ
  Шаг 10: Ранжирование по потенциалу адаптации
  Шаг 11: Подготовка ТОП-5 с аннотациями
  Шаг 12: Отправка результатов Manager и Trend Analyst
```

  Comments: 2,800

  Ratio: 2.5x

## 🔥 АГЕНТ #4: ТРЕНДОЛОГ (Trend Analyst Agent)

### Основная информация
```
Статус:     ✅ Переопределен для v4.1
Приоритет:  ⭐⭐⭐ КРИТИЧНЫЙ
Роль:       Анализ структуры видео (транскрибация + выделение компонентов)
Версия:     v4.1
Время:      1 день на 5 видео
```

### Основные функции
```
1. Транскрибировать видео (в текст)
2. Выявить структуру (хук, основное сообщение, призыв)
3. Найти ключевые фразы
4. Выявить психологические триггеры
5. Определить жанр и стиль
6. Дать рекомендации для переписывания
```

### Входящие данные
```
- 5 видео от Scout (ссылки + метрики)
- Информация о целевой аудитории
```

### Выходящие данные
```
Для каждого видео:
  - Полная транскрибация (текст видео)
  - Структура:
    * Хук (первые 3 секунды) — что заставило смотреть
    * Основное сообщение (суть видео)
    * Призыв (CTA — что делать после)
  - Ключевые фразы (топ 10)
  - Психологические триггеры (используемые техники)
  - Жанр и стиль (ораторский, развлекательный, образовательный)
  - Советы по переписыванию (как адаптировать под свою аудиторию)

Пример:
  Видео: "История Славян"
  Хук: "Это, то что скрывали от вас в школе..."
  Основное сообщение: Детальная история славяно-арийской цивилизации
  Призыв: "Подписывайся на канал, чтобы узнать ещё больше"
  Триггеры: Интрига (скрытая информация), авторитет (автор эксперт), срочность
```

### Процесс работы (1 день на 5 видео)
```
Видео #1 (3 часа):
  Шаг 1: Загрузить видео
  Шаг 2: Транскрибировать через Whisper/AssemblyAI
  Шаг 3: Прочитать текст и выделить структуру
  Шаг 4: Найти ключевые фразы (NLP)
  Шаг 5: Определить триггеры
  Шаг 6: Выдать анализ

[Повторить для видео #2-5, параллельно процессы]
```

### Пример анализа видео

```
=== АНАЛИЗ ВИДЕО: "ИСТОРИЯ СКИФОВ" ===

СТРУКТУРА:
  Хук (0-3 сек): "Я буду честно с вами. То, что вы узнаете 
                  сейчас, может перевернуть всё, что вы знали"
  
  Основное сообщение (3-8 мин): Детальная история Скифского 
                                 царства, их культуры и влияния
  
  Призыв (в конце): "Если вам нравится история, подписывайтесь 
                     и включите уведомления"

КЛЮЧЕВЫЕ ФРАЗЫ:
  1. "Скрытая история"
  2. "Никто не говорит об этом"
  3. "Это изменит ваше мышление"
  4. "Подписывайтесь"
  5. "Это критично знать"

ТРИГГЕРЫ:
  - Интрига: "то, что скрывали"
  - Авторитет: автор выглядит экспертом
  - Срочность: "это нужно знать сейчас"
  - Любопытство: "перевернёт всё что вы знали"
  - Социальное доказательство: много лайков/комментариев

РЕКОМЕНДАЦИЯ ДЛЯ ПЕРЕПИСЫВАНИЯ:
  ✓ Сохранить хук (это работает)
  ✓ Добавить больше фактов с источниками
  ✓ Усилить визуальный контент (карты, графики)
  ✓ Сделать CTA более понятным (не просто "подписывайтесь")
  ✓ Добавить скорости в конце видео (монтаж)
```

### Скиллы которые нужны
```
- Whisper / AssemblyAI (транскрибация)
- NLP (выделение ключевых слов)
- Анализ психологических триггеров
- Понимание структуры видеоконтента
- Опыт в создании контента
```

## ✍️ АГЕНТ #5: КОПИРАЙТЕР (Copywriter Agent)

### Основная информация
```
Статус:     ✅ Существует
Приоритет:  ⭐⭐⭐ КРИТИЧНЫЙ
Роль:       Создание промптов для видео
Версия:     v3.0
Время:      2-3 часа на 15 промптов
```

### Основные функции
```
1. Получить анализ от Trend Analyst
2. Создать 3 варианта промпта на каждое видео (15 промптов всего)
3. Каждый вариант должен быть оригинальным (не плагиат)
4. Адаптировать под целевую аудиторию
5. Включить психологические триггеры
6. Оптимизировать для каждой платформы
```

### Входящие данные
```
- Анализ от Trend Analyst (структура, триггеры, рекомендации)
- Информация о целевой аудитории (от Audience Researcher)
- Предыдущие успешные промпты (если есть)
```

### Выходящие данные
```
15 промптов (3 на каждое видео):
  Для видео #1:
    1. Вариант A (эмоциональный)
    2. Вариант B (логический)
    3. Вариант C (urgency-driven)
  
  [То же для видео #2-5]
  
Каждый промпт включает:
  - Заголовок
  - Основной текст (2-3 строки)
  - CTA (призыв к действию)
  - Хэштеги (если нужны)
```

### Процесс работы (2-3 часа)
```
ДЛЯ КАЖДОГО ВИДЕО (30 мин):
  Шаг 1: Изучить анализ от Trend Analyst
  Шаг 2: Понять целевую аудиторию
  Шаг 3: Создать вариант A (эмоциональный на триггере интриги)
  Шаг 4: Создать вариант B (логический с фактами)
  Шаг 5: Создать вариант C (с urgency и ограничением по времени)
  Шаг 6: Пересчитать, чтобы не было плагиата
  Шаг 7: Оптимизировать для TikTok/Instagram/YouTube

[ПОВТОРИТЬ для 5 видео = 5 × 30 мин = 2.5 часа]
```

## 👥 АГЕНТ #9: AUDIENCE RESEARCHER (НОВЫЙ!)

### Основная информация
```
Статус:     ❌ НУЖНО СОЗДАТЬ
Приоритет:  ⭐⭐⭐ КРИТИЧНЫЙ
Роль:       Исследование и анализ целевой аудитории
Время:      1-2 дня на исследование
```

### Основные функции
```
1. Определить целевую аудиторию (age, gender, interests)
2. Создать 3-5 buyer personas
3. Выявить их проблемы (pain points)
4. Определить их желания (desires)
5. Найти триггеры покупки
6. Дать рекомендации по контенту
```

### Входящие данные
```
- Тема контента (например: "Славяно-Арийская культура")
- История предыдущих успешных контентов
- Целевой рынок (география, язык)
```

### Выходящие данные
```
Отчет о целевой аудитории:
  - Демография (возраст, пол, локация)
  - Психография (интересы, ценности, образ жизни)
  - Боли (что их беспокоит)
  - Желания (чего они хотят)
  - Триггеры покупки
  - 3-5 Buyer Personas (детальные портреты)
  - Рекомендации по контенту
```

### Пример Buyer Persona

```
=== PERSONA #1: "Историк Иван" ===
Демография:
  - Возраст: 35-45 лет
  - Пол: Мужской
  - Образование: Высшее
  - Доход: $1500-3000/месяц
  
Интересы:
  - История
  - Культура
  - Образование
  - Саморазвитие
  
Боли:
  - Чувствует, что его обманули в школе
  - Хочет узнать истину о своих корнях
  - Ищет информацию, которая не в учебниках
  
Желания:
  - Стать экспертом по истории
  - Поделиться знанием с семьей
  - Найти сообщество единомышленников
  
Триггеры покупки:
  - "Скрытая информация"
  - "Только для инсайдеров"
  - "Эксклюзивный доступ"
  - "Ограниченное предложение"

Рекомендация контента:
  → Подробные исторические материалы
  → Качественное визуальное оформление
  → Ссылки на источники

```

```

```
