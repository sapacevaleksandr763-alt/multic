## 🚀 Быстрый Старт

### Шаг 1: Проверка Структуры

```bash
# Убедиться, что все репозитории клонированы
ls -la ./marketing-repo/skills/ | wc -l  # Должно быть 60+
ls -la ./skills-repo/skills/ | wc -l      # Должно быть 106
ls -la ./knowledge-repo/                   # Должно быть много категорий
```

### Шаг 2: Создать Симлинки (опционально)

```bash
# Для удобства в каждой папке агента
ln -s ../marketing-repo/skills ./marketing-skills
ln -s ../skills-repo/skills ./social-skills
ln -s ../knowledge-repo ./knowledge-work
```

### Шаг 3: Интеграция в Код

```python
# agents.py
SKILLS_PATHS = {
    'marketing': './marketing-repo/skills/',
    'social_media': './skills-repo/skills/',
    'knowledge_work': './knowledge-repo/'
}

# Загрузить нужные навыки для агента
def load_agent_skills(agent_name):
    skills_config = AGENT_SKILLS.get(agent_name, [])
    loaded_skills = []
    
    for skill_name in skills_config:
        for path in SKILLS_PATHS.values():
            skill_path = f"{path}/{skill_name}/"
            if os.path.exists(skill_path):
                loaded_skills.append({
                    'name': skill_name,
                    'path': skill_path
                })
                break
    
    return loaded_skills
```
