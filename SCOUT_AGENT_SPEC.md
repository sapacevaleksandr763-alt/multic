## 🔄 Процесс работы (пошагово)

### Фаза 1: Поиск (каждый день в 09:00 МСК)
```
1. Подключиться к YouTube API
2. Выполнить поиск по запросу: "Славяно-Арийская культура"
3. Отфильтровать видео по параметрам:
   - Минимум 100 лайков
   - Минимум 50 комментариев
   - Дата: за последние 30 дней
4. Сортировать по engagement ratio (лайки + комментарии / просмотры)
5. Выбрать ТОП-5 видео
```

### Фаза 2: Анализ
```
6. Для каждого видео собрать:
   - Все метаданные (название, канал, ссылка)
   - Статистику (просмотры, лайки, комментарии)
   - Теги и категорию
   - Описание и дату публикации
7. Рассчитать engagement ratio (популярность)
8. Проверить, не был ли уже отправлен этот результат ранее
```

### Фаза 3: Отправка в Telegram
```
9. Отправить результаты в Telegram канал @nasledieariev
10. Формат сообщения:
    📺 [RANK 1/5] Название видео
    👤 Канал: Название
    👁️ Просмотры: 1.5M | 👍 Лайки: 45K | 💬 Комментарии: 2.3K
    ⚡ Engagement: 3.1%
    🔗 https://youtube.com/watch?v=...
```

### Фаза 4: Сохранение в БД
```
11. Сохранить результат в локальную БД (SQLite)
    - video_id
    - title
    - channel
    - stats
    - date_found
    - status (new/analyzing/analyzed)
12. Обновить счетчик найденных видео за день
```

## 🛠️ Техническая реализация

### Стек:
- **Python 3.10+** — основной язык
- **youtube-api-python-client** — YouTube API
- **python-telegram-bot** — Telegram интеграция
- **SQLite3** — локальная БД для истории поиска
- **APScheduler** — планировщик (cron jobs)
- **requests** — HTTP запросы
- **dotenv** — переменные окружения

### Файловая структура:
```
multic/
├── .env                          # API ключи (НЕ коммитить!)
├── requirements.txt              # Python зависимости
├── scout_agent.py               # Основной скрипт Scout Agent

├── database.py                  # SQLite операции
├── config.py                    # Конфигурация
└── logs/                        # Логи выполнения
```

## 🚨 Обработка ошибок

| Ошибка | Обработка |
|--------|-----------|
| YouTube API недоступен | Повторить запрос через 60 сек, макс 3 попытки |
| Telegram недоступен | Логировать ошибку, повторить через 5 мин |
| Нет найденных видео | Отправить уведомление "Видео не найдены" |
| Invalid API Key | Заморозить, уведомить пользователя |
| Сетевая ошибка | Автоматический retry с exponential backoff |
