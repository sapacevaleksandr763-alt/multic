## 🔄 DATA FLOW

```
DAY 1:
  09:00 → Scout Agent запускается
  09:02 → Поиск видео на YouTube (50 видео)
  09:04 → Фильтрация (ТОП-5)
  09:05 → Отправка в Telegram + сохранение в БД

DAY 1-7:
  Every 8 hours → Copywriter генерирует варианты контента
  A/B тестирование лучших вариантов

DAY 7-14:
  Promotion Agent публикует лучшие варианты на 6 платформ
  по оптимальному расписанию

EVERY DAY:
  Analytics собирают статистику
  Dashboard обновляется в real-time
  Система учится из результатов (A/B тесты)
```
