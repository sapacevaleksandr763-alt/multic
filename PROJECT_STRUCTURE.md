## 🎯 КАК ИСПОЛЬЗОВАТЬ СТРУКТУРУ?

### ДЛЯ БЫСТРОГО ПОИСКА:

1. **"Какие правила работы?"** → Читай `CLAUDE.md`
2. **"Как устроена система?"** → `knowledge/COMPLETE_ARCHITECTURE.md`
3. **"Как взаимодействуют агенты?"** → `knowledge/INTEGRATION_MAP.md`
4. **"Детали конкретного агента?"** → `knowledge/DETAILED_AGENTS.md`
5. **"Какие агенты нужны?"** → `AGENTS_ANALYSIS_NEEDED_AGENTS.md`
6. **"4-шаговый процесс?"** → `INSTRUCTION_VIDEO_CREATION_4STEPS.md`
7. **"Какие скиллы установить?"** → `ADDITIONAL_SKILLS.md`

### ДЛЯ ПЕРИОДИЧЕСКИХ ПРОВЕРОК:

**Ежедневно:**
- Проверь `GOALS.md` (в разделе "Статус по датам")
- Проверь `PROJECT_STATUS_v4.0.md` (что в работе)

**Еженедельно:**
- Обновляй `memory/MEMORY.md` (если есть что помнить)
- Добавляй в `knowledge/` новые файлы (если нужны)

**Ежемесячно:**
- Пересчитывай `GOALS.md` (финансовые метрики)
- Обновляй `PROJECT_STATUS_v4.0.md`

## 🔄 КАК ОБНОВЛЯТЬ ФАЙЛЫ?

### Когда добавляется новый агент:

1. Обнови `AGENTS_ANALYSIS_NEEDED_AGENTS.md` (добавь в таблицу)
2. Создай `[AGENT_NAME]_SPEC.md` (спецификация)
3. Обнови `knowledge/DETAILED_AGENTS.md` (добавь детали)
4. Обнови `knowledge/INTEGRATION_MAP.md` (добавь зависимости)
5. Обнови `AGENTS.md` (добавь в список)
6. Обнови `ADDITIONAL_SKILLS.md` (какие скиллы нужны)

### Когда меняется бизнес-цель:

1. Обнови `GOALS.md` (новые цели)
2. Обнови `SOUL.md` (если меняется характер)
3. Обнови `CLAUDE.md` (если меняются правила)

### Когда добавляется новый файл:

1. Добавь в `00_CONTENTS.md`
2. Обнови `PROJECT_STRUCTURE.md` (этот файл)
3. Добавь в память (если нужно помнить)

3. Читай нужные `knowledge/` файлы
4. Выполняй согласно инструкциям

## 💾 РЕЗЕРВНАЯ КОПИЯ И СИНХРОНИЗАЦИЯ

### Как скопировать всю структуру на сервер:

```bash
# Скопировать все .md файлы на сервер
scp -r ~/multic/*.md server:/path/to/multic/

# Скопировать память и знания
scp -r ~/multic/memory/ server:/path/to/multic/
scp -r ~/multic/knowledge/ server:/path/to/multic/
```

### Как интегрировать с Telegram ботом:

```python
# Telegram Bot может читать эти файлы и отвечать на вопросы:

commands = {
    "/rules" → читай CLAUDE.md,
    "/goals" → читай GOALS.md,
    "/agents" → читай knowledge/COMPLETE_ARCHITECTURE.md,
    "/integration" → читай knowledge/INTEGRATION_MAP.md,
    "/status" → читай PROJECT_STATUS_v4.0.md,
}
```
