## 👥 Команда Агентов

### 1. 🎯 **Управляющий** (Manager)
- **Роль:** Координация всей системы
- **Функция:** Постановка задач, интеграция результатов
- **Скиллы:** launch, marketing-ideas, campaign-planner, resource-allocation

### 2. 📊 **Стратег** (Strategist)
- **Роль:** Разработка стратегии продвижения
- **Функция:** Анализ аудитории, позиционирование, планирование
- **Скиллы:** product-marketing, competitor-analysis, pricing, audience-insights

### 3. 🔥 **Трендолог** (Trend Analyst)
- **Роль:** Отслеживание трендов и вирусности
- **Функция:** Выявление актуальных форматов, звуков, тем
- **Скиллы:** viral-mechanics, trending-topics, benchmark, ai-search-optimization

### 4. 🕵️ **Разведчик** (Competitor Intelligence)
- **Роль:** Анализ конкурентов
- **Функция:** SWOT, выявление gaps, дифференциация
- **Скиллы:** competitor-profiling, social-analytics, sentiment-analysis

### 5. ✍️ **Копирайтер** (Content Writer)
- **Роль:** Создание контента
- **Функция:** Тексты, скрипты, адаптация под аудиторию
- **Скиллы:** copywriting, hook-writer, storytelling, content-generator

### 6. 🎨 **Мультиформатник** (Format Creator)
- **Роль:** Адаптация контента под платформы
- **Функция:** Оптимизация под алгоритмы, форматирование
- **Скиллы:** cross-platform-repurposing, instagram-strategy, tiktok-strategy

### 2. Проверить локальные репозитории
```bash
# Проверить Marketing Skills
ls -la ./marketing-repo/skills/ | head -20

# Проверить Social Media Skills
ls -la ./skills-repo/skills/ | head -20

# Проверить Knowledge Work
ls -la ./knowledge-repo/
```

### 3. Выбрать скилл для изучения
```bash
# Например, для копирайтера:
cat ./marketing-repo/skills/copywriting/SKILL.md

```

### 4. Интегрировать в код (позже)
```python
# Будет создано на этапе разработки
from agents import Manager, Strategist, TrendAnalyst, ...
from skills_loader import load_skills

# Загрузить скиллы для каждого агента
manager = Manager(skills=load_skills('manager'))
strategist = Strategist(skills=load_skills('strategist'))
# ...
```

## 🔄 Workflow Системы

### Типичный Сценарий: Запуск Продвижения Нового Товара

```
1. Управляющий получает задачу
   ↓
2. Управляющий ставит задачи:
   ├─ Стратег → разработка стратегии
   ├─ Трендолог → анализ трендов
   ├─ Разведчик → анализ конкурентов
   └─ Копирайтер → создание контент-плана
   ↓
3. Копирайтер создает тексты и идеи
   ↓
4. Мультиформатник адаптирует под платформы
   ↓
5. Все результаты интегрируются Управляющим
   ↓
6. Система готова к публикации
```

## 💡 Примеры Использования

### Пример 1: Анализ Конкурента

```
Управляющему: "Проанализировать стратегию конкурента X"

Система выполнит:
- Разведчик: SWOT-анализ, benchmark по метрикам
- Трендолог: анализ их используемых трендов
- Копирайтер: анализ их типов контента и CTA
- Мультиформатник: оценка адаптации контента

Результат: комплексный отчет с рекомендациями
```

### Пример 2: Подготовка Недельного Контента

```
Управляющему: "Подготовить контент на неделю"

Система выполнит:
- Стратег: определить тему недели и направление
- Трендолог: выбрать актуальные тренды и звуки
- Копирайтер: написать 20+ вариантов контента
- Мультиформатник: адаптировать под 6 платформ

Результат: готовые посты для публикации
```

### Пример 3: Кризис-Менеджмент

```
Управляющему: "Конкурент запустил агрессивную кампанию"

Система выполнит:
- Разведчик: быстрый анализ кампании
- Стратег: определить контр-стратегию
- Копирайтер: подготовить остро-актуальный контент
- Мультиформатник: срочно адаптировать

Результат: контр-кампания в течение часов
```

1. **Прочитайте документацию**

   - Интегрируйте 2-3 скилла
   - Протестируйте на простой задаче

4. **Постепенно расширяйте**
   - Добавляйте новые скиллы
