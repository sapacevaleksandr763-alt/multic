## 📝 Content Strategy Skill (из AAS)

**Назначение:**
Специализированный скилл для структурированного планирования контента. Превращает хаотичные идеи в организованный контент-план с четкой стратегией.

### Что Делает:

✅ **Собирает контент-план вместо отдельных идей**
- Структурирует все идеи в единый план
- Определяет темы, углы, форматы
- Расставляет приоритеты

✅ **Определяет стратегию**
- Целевая аудитория
- Основные сообщения
- Метрики успеха

✅ **Организует по времени**
- График публикаций
- Очередность контента
- Сезонность

✅ **Интегрирует с другими скиллами**
- Связует с брендовой стратегией
- Учитывает аналитику
- Адаптирует под платформы

### Для Каких Агентов:

**Копирайтер** ⭐⭐⭐
- Основной контент-план для недели/месяца
- Структурирование тем
- Угловка каждого поста

**Мультиформатник** ⭐⭐
- Планирование адаптации контента
- Расчет форматов по времени

**Управляющий** ⭐⭐
- Контроль контент-плана
- Синхронизация с общей стратегией

### Пример Использования:

```
Копирайтеру: "Создай контент-план на месяц для [объект]"

Скилл выдаст:
├─ Неделя 1: Тема "Основы", 4 поста разных форматов
├─ Неделя 2: Тема "Преимущества", 5 постов
├─ Неделя 3: Тема "Применение", 3 поста
└─ Неделя 4: Тема "Отзывы", 4 поста

+ Каждый пост с указанием:
  ├─ Целевой аудитории
  ├─ Угла/идеи
  ├─ Рекомендуемого формата
  ├─ Времени публикации
  └─ KPI для отслеживания
```

### Параметры Конфигурации:

```json
{
  "content_strategy": {
    "planning_horizon": "monthly",  // weekly, monthly, quarterly
    "platforms": ["instagram", "tiktok", "telegram"],
    "formats": ["carousel", "reel", "short", "post"],
    "themes_per_period": 4,
    "posts_per_theme": 4,
    "include_analytics": true,
    "include_seasonality": true,
    "optimize_for": "engagement"  // reach, engagement, conversion
  }
}
```

### Интеграция в Систему:

**Файл:** `./content-strategy-repo/`

**Путь в коде:**
```python
from skills import ContentStrategySkill

# Для Копирайтера
copywriter_skills = [
    'copywriting',
    'hook-writer',
    'content-strategy',  # ← ЭТО НОВОЕ
    'storytelling'
]

# Использование

    objective="Продвижение товара X",
    duration="monthly",
    target_audience="20-35, интересуются интернетом",
    platforms=["instagram", "tiktok", "telegram"]
)
```

### Преимущества:

| Аспект | Результат |
|--------|-----------|
| **Структурированность** | 100% организованный план вместо хаоса |
| **Консистентность** | Единая тема, разные углы |
| **Эффективность** | Копирайтер знает точно, что писать |
| **Масштабируемость** | План на месяц вместо дневных идей |
| **Синергия** | Легко адаптировать под разные платформы |

## 📋 Как Это Вписывается в Систему

### Workflow с Content Strategy Skill:

```
Управляющий получает задачу
    ↓
Управляющий ставит задачу Копирайтеру:
"Создай контент-план на месяц"
    ↓
Копирайтер использует Content Strategy Skill:
├─ Определяет целевую аудиторию
├─ Выбирает основные темы
├─ Структурирует по времени
└─ Создает план
    ↓
Content Strategy Skill выдает:
├─ Неделя 1: 4 темы × 4 поста = 16 вариантов
├─ Неделя 2: 4 темы × 4 поста = 16 вариантов
├─ Неделя 3: 4 темы × 4 поста = 16 вариантов
└─ Неделя 4: 4 темы × 4 поста = 16 вариантов
    ↓
Копирайтер пишет черновики на основе плана
    ↓
Мультиформатник адаптирует под платформы
    ↓
Управляющий интегрирует в финальный календарь
```

### Синергия со Скиллами:

**Content Strategy + Marketing Skills:**
- `product-marketing` — определяет основные углы

**Content Strategy + Social Media Skills:**
- `hook-writer` — пишет хуки для каждого поста
- `cross-platform-repurposing` — адаптирует план под платформы
- `viral-mechanics` — оптимизирует план под вирусность

**Content Strategy + Knowledge Work:**
- `marketing/content-draft` — использует план для черновиков
- `marketing/campaign-brief` — интегрирует план в кампанию
