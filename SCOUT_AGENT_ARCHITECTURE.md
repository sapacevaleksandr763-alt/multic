## 📋 ОБЗОР

Scout Agent — 7-й специализированный агент в системе MULTIC, отвечающий за веб-разведку, мониторинг и сбор данных в реальном времени.

**Роль:** Агент-разведчик для поиска вирусного контента, трендов и конкурентной информации

---

## 🎯 ОСНОВНЫЕ ФУНКЦИИ

### 1. 🔍 **Поиск информации в интернете**
- Веб-поиск через Brave Search API
- Фильтрация по релевантности
- Сбор метаданных (URL, заголовок, описание)

### 2. 🕵️ **Мониторинг сайтов и источников**
- Отслеживание изменений на сайтах
- RSS-feed мониторинг
- Алерты при появлении нового контента

### 3. 📱 **Поиск в социальных сетях**
- YouTube Search (видеоролики)
- Twitter/X API (социальные тренды)
- ВКонтакте API (если доступен)
- Instagram (через scraping или API)

### 4. 🎥 **Поиск видеоконтента**
- YouTube Search API
- Фильтрация по метрикам (просмотры, лайки)
- Анализ описаний и комментариев

### 5. 📊 **Сбор данных для аналитики**
- Агрегация статистики
- Анализ тренды
- Подготовка отчетов

### 6. 🖼️ **Поиск изображений**
- Wikimedia Commons
- Локальная библиотека (fallback)
- Оптимизированный поиск

### 7. 🔗 **Отслеживание трендов**
- Мониторинг популярных тем
- Анализ вирусности
- Прогнозирование трендов

## 🛠️ ИНСТРУМЕНТЫ И СКИЛЛЫ

### A. ВСТРОЕННЫЕ СКИЛЛЫ CLAUDE

#### 1. `/investigate` (из gstack)
```
Назначение: Расследование и диагностика
Использование: Для глубокого анализа проблем
Пример: /investigate "почему видео не вирусное"
```

#### 2. `investigate` (встроенный)
```
Назначение: Открытая разведка и исследование
Использование: Основной скилл для поиска информации
Пример: Анализ трендов, сбор данных
```

#### 3. `content-research-writer`
```
Назначение: Исследовательское письмо с источниками
Использование: Создание аналитических отчетов
Пример: Отчет о вирусных видео с ссылками
```

#### 4. `browse` (встроенный)
```
Назначение: Быстрый браузинг сайтов
Использование: Чтение конкретных URL
Пример: Открыть YouTube и получить статистику
```

### B. ВНЕШНИЕ API (БЕСПЛАТНЫЕ)

#### 1. **Brave Search API** ⭐ ГЛАВНЫЙ
```
Назначение: Веб-поиск
Получение ключа: https://brave.com/search/api (бесплатно)
Лимит: 2000 запросов/день бесплатно
Использование:
  - Поиск видеороликов
  - Поиск статей
  - Поиск источников
```

#### 2. **YouTube Data API**
```
Назначение: Поиск видео, статистика
Получение: https://console.developers.google.com/
Лимит: 10,000 запросов/день бесплатно
Используется для:
  - Поиск видео по теме
  - Получение просмотров, лайков, комментариев
  - Анализ описаний видео
```

#### 3. **VK API** (ВКонтакте)
```
Назначение: Поиск в ВКонтакте
Получение: https://vk.com/dev/access_token
Лимит: 3 запроса/сек для сервера
Используется для:
  - Поиск видео в ВКонтакте
  - Поиск в группах
  - Сбор статистики
```

#### 4. **Wikimedia Commons API**
```
Назначение: Поиск изображений
Использование: Свободные изображения для контента
Бесплатно: Полностью
```

#### 5. **Twitter/X API** (опционально)
```
Назначение: Поиск трендов
Бесплатный уровень: Ограничен, но доступен
Используется для:
  - Мониторинг трендов
  - Поиск популярного контента
```

## 🎯 ИСПОЛЬЗОВАНИЕ СКИЛЛОВ

### Скилл 1: `/investigate` (для анализа)
```python
# Использование в коде Scout Agent:

def analyze_video_virality(video_data):
    """
    Использует /investigate для глубокого анализа
    """
    investigation = claude.investigate(
        topic=f"Почему видео '{video_data['title']}' стало вирусным",
        data=video_data
    )
    return investigation
```

### Скилл 2: `investigate` (основной поиск)
```python
def research_topic(topic, niche):
    """
    Основной скилл для разведки информации
    """
    research = claude.investigate(
        topic=f"Лучшие видео по теме '{topic}' в нише '{niche}'",
        search_depth="deep"
    )
    return research
```

### Скилл 3: `content-research-writer`
```python
def generate_report(videos_data, topic):
    """
    Создает аналитический отчет
    """
    report = claude.content_research_writer(
        topic=f"Анализ вирусных видео: {topic}",
        data=videos_data,
        include_sources=True
    )
    return report
```

### Скилл 4: `browse` (для чтения конкретных сайтов)
```python
def check_specific_url(url):
    """
    Открывает и анализирует конкретную страницу
    """
    content = claude.browse(url)
    return content
```
