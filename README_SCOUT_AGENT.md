## 📝 Краткое описание

**Scout Agent** — автоматизированная система поиска вирусных видео по тематике "Славяно-Арийская культура" на YouTube. Система ежедневно ищет топ-5 видео и отправляет результаты в Telegram для анализа структуры, хуков и трендов.

### Основные функции:
- ✅ Поиск видео на YouTube API
- ✅ Фильтрация по лайкам (>100) и комментариям (>50)
- ✅ Расчет Engagement Ratio (популярность видео)
- ✅ Отправка результатов в Telegram
- ✅ Сохранение в SQLite БД для анализа
- ✅ Автоматический запуск каждый день в 09:00 МСК

## 🔄 Как это работает

### Фаза 1: Поиск видео (YouTube API)
```
1. Подключиться к YouTube API с ключом из .env
2. Выполнить поиск: "Славяно-Арийская культура" + фильтры
3. Получить первые 50 видео
```

### Фаза 2: Фильтрация и анализ
```
4. Для каждого видео получить статистику:
   - Просмотры (views)
   - Лайки (likes)
   - Комментарии (comments)
5. Отфильтровать по минимальным значениям:
   - likes >= 100
   - comments >= 50
6. Рассчитать Engagement Ratio = (likes + comments) / views * 100%
7. Выбрать топ-5 по engagement
```

### Фаза 3: Отправка в Telegram
```
8. Отправить сводку (summary) с результатами поиска
9. Отправить детальное сообщение для каждого видео:
   - Название
   - Канал
   - Статистика (просмотры, лайки, комментарии)
   - Engagement %
   - Ссылка на видео
```

### Фаза 4: Сохранение в БД
```
10. Добавить все найденные видео в SQLite БД
11. Логировать результаты поиска (дата, кол-во видео, ошибки)
```

## 🗂️ База данных (SQLite)

### Таблица `videos`:
```
id            - Уникальный ID (автоинкремент)
video_id      - ID видео YouTube (UNIQUE)
title         - Название видео
channel       - Название канала
url           - Полная ссылка
views         - Кол-во просмотров
likes         - Кол-во лайков
comments      - Кол-во комментариев
engagement_ratio - Процент (лайки + комментарии) / просмотры
description   - Описание (первые 500 символов)
tags          - JSON массив тегов
published_at  - Дата публикации на YouTube
date_found    - Дата когда видео было найдено Scout Agent
status        - Статус (new/analyzing/analyzed)
created_at    - Дата добавления в БД
```

### Таблица `search_logs`:
```
id                  - Уникальный ID
search_date         - Дата и время поиска
videos_found        - Кол-во найденных видео
top_videos_sent     - Кол-во отправленных в Telegram
status              - Статус (success/error/no_new_videos)
error_message       - Текст ошибки (если была)
execution_time_sec  - Время выполнения в секундах
created_at          - Дата добавления записи
```

## 🐛 Обработка ошибок

### Общие ошибки и решения:

| Ошибка | Решение |
|--------|---------|
| "YOUTUBE_API_KEY не установлен" | Добавьте ключ в `.env` файл |
| "YouTube API недоступен" | Проверьте интернет, повторите позже |
| "Telegram Bot Token не установлен" | Передайте токен через `/mybots` в BotFather |
| "Ошибка подключения к Telegram" | Проверьте Token, интернет соединение |
| "Видео не найдены" | Попробуйте другой запрос или увеличьте лимит |

### Система обработки ошибок:
- ✅ Автоматический retry с экспоненциальным бэкоффом
- ✅ Логирование всех ошибок в `logs/scout_agent.log`
- ✅ Отправка уведомлений об ошибках в Telegram
- ✅ Граничное оптимальное обеспечение (rate limiting)
